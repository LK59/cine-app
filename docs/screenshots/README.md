# Screenshots

This folder is empty on purpose: the previous set was captured before the redesign and was
deleted rather than left to describe an interface that no longer exists.

What still needs capturing is written where it is used — each shot is an HTML comment in
`README.md` or `DEPLOYMENT.md` naming the file to produce, what to frame, and the `<img>` tag to
uncomment once the file is here. There is no second list to keep in sync:

```sh
grep -n 'CAPTURE :' README.md DEPLOYMENT.md
```

Conventions: PNG, lowercase filenames exactly as the placeholder names them (the `<img>` tags are
already written against them), desktop shots at 1920×1080 in the dark theme, phone shots from one
device, and the same handful of titles across all of them so the library reads as one library.
