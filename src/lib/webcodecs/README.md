La documentation technique de ce lecteur vit à la racine du dépôt :
**[`DOC-TECH.md`](../../../DOC-TECH.md)**.

Elle y est plutôt qu'ici pour une raison bête et suffisante : GitHub n'affiche
que les fichiers de la racine sur la page d'accueil d'un dépôt, et enterrée à
trois niveaux de profondeur elle était introuvable pour qui lit le dépôt plutôt
que le code.

Un seul document, pas deux : une copie aurait divergé de l'original en quelques
semaines, et deux documentations qui se contredisent valent moins que pas de
documentation du tout.
